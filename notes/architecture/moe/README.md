# MoE 架构：Router、负载均衡与专家组织

Mixture of Experts（MoE，混合专家）把一个很大的前馈网络拆成多个专家，让每个 token 只激活其中少数几个专家。这样可以增加总参数量，同时控制每个 token 实际参与计算的参数量。

## 阅读顺序

1. [为什么需要 MoE](01-为什么需要MoE.md)：稠密 FFN 的计算瓶颈与稀疏激活的基本想法。
2. [Router 与 Top-k 路由](02-Router与Top-k路由.md)：路由分数、专家选择、容量和 token dispatch。
3. [负载均衡损失](03-负载均衡损失.md)：importance/load、辅助损失、溢出与实际均衡。
4. [细粒度专家与共享专家](04-细粒度专家与共享专家.md)：细分 FFN、shared expert、组合结构与工程取舍。
5. [训练与推理实现](05-训练与推理实现.md)：通信、容量因子、丢 token、吞吐和面试追问。
