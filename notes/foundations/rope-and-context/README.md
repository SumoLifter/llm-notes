# 旋转位置编码与上下文长度扩展

RoPE 解决的是：**让注意力计算带上两个 token 之间的相对位置。**

长度扩展解决的是：**让原来只在短序列上训练过的模型，在更长序列上仍然有效。** 两者有关，但会计算更大的位置编号，并不意味着模型已经会处理长文本。

## 本专题使用的约定

位置从 0 开始。4K 表示 4,096 个 token，32K 表示 32,768 个 token；token 不等于汉字，也不等于单词。

示例采用一个注意力头的旋转维度 `d = 128`、RoPE 底数 `b = 10,000`。它们用于说明原理，不是所有模型的统一配置。

图都是按明确公式计算的教学示例。几何曲线不当作模型性能证据，模拟注意力不当作真实模型测量结果。
